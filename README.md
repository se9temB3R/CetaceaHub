# CetaceaHub

**CetaceaHub** 是一款运行于 Windows 的 QQ 机器人桌面管理软件：图形化界面一键启停机器人、管理人格与模型、监控日志与用量，无需任何命令行操作。

> 本仓库为 CetaceaHub 的官方发布渠道，提供软件更新信息与安装包下载。项目源代码不在本仓库。

## ✨ 功能特性

- **图形化控制台** — 一键启动 / 全部停止 / 一键重启，实时状态灯与日志（自动脱敏）
- **人格系统** — 内置鲸鱼女孩「塞塔西娅（Cetacea）」人格，支持对话式生成与修改人格
- **模型 API 管理** — 支持 DeepSeek、OpenAI 兼容接口、Anthropic 协议，界面内增删改模型档
- **智能运维** — 崩溃自动重启看门狗、每日自动备份、一键诊断、日志轮转
- **自动化更新** — 启动与每日自动检查新版本，发现更新时界面横幅 + 托盘气泡提醒
- **数据安全** — API 密钥以 Windows 用户级加密存储，卸载保留全部记忆与配置

## 📥 快速开始

1. 前往 [Releases](../../releases) 下载最新版 `CetaceaHubSetup-x.y.z.exe`
2. 运行安装包（SmartScreen 提示请点击「更多信息 → 仍要运行」）
3. 首次启动跟随向导：填写 DeepSeek API Key → 设置管理员 QQ → 完成
4. 主界面点击「🚀 一键启动」，在 QQ 网页界面扫码登录机器人账号
5. 群聊中 @机器人 或喊「塞塔西娅」即可对话

## 🎮 使用方式

| 场景 | 方式 |
|---|---|
| 群聊对话 | @机器人 或喊触发词（塞塔西娅 / Ceta / 娅娅 / 鲸鱼女孩） |
| 联网搜索 | 发送 `/搜索 <问题>`（每人每日限次） |
| 图片识别 | 发送图片并 @机器人 |
| 帮助 | 发送 `/help` |
| 管理指令 | `/生成人格` `/修改人设` `/用量` `/模型列表` `/切换模型` 等（仅管理员） |

## 🔄 更新机制

软件内置更新检查：启动后及每日自动查询一次更新源，发现新版本时在界面顶部显示下载横幅，点击即可跳转下载。也可在「管理员工具 → 检查更新」手动触发。
